# LinkedIn post skill for Codex

This is a Codex-compatible adaptation of the `li-post` workflow from [Jakeschincariol/linkedin-agent-skill](https://github.com/Jakeschincariol/linkedin-agent-skill), licensed under MIT. The original repository is preserved separately under `work/linkedin-agent-skill` for reference. This adaptation contains the post-writing workflow and hook formulas; it does not include or claim the source project's other 10 skills or the Python humanizer.

## Install

Copy this directory to your Codex skills directory, usually `%USERPROFILE%\.codex\skills\linkedin-post`. Start a new Codex turn/session if it does not appear immediately. You can also use it in the current workspace by keeping this directory under `.agents/skills/linkedin-post`.

Use it by asking for a LinkedIn post, for example: `Use the linkedin-post skill: write a post about [specific idea].`

The skill drafts only. It does not post or schedule to LinkedIn or Typefully.
